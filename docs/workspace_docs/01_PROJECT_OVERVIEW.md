# Project Overview

## Purpose
Health Tracker is a Flutter app with Firebase integration for authentication and health tracking flows.

## Tech Stack
- Flutter / Dart
- Firebase Core, Firebase Auth, Cloud Firestore
- Android, iOS, Windows, Web, macOS, Linux targets

## Main Areas
- lib/: app source code
- assets/: images/icons/static assets
- test/: widget and unit tests
- android/, ios/, windows/, web/, macos/, linux/: platform runners

## Core Layers in lib/
- core/: routes, themes, app-level config
- controllers/: business logic controllers
- models/: data models
- services/: integrations and infrastructure logic
- views/ and screens/: UI
